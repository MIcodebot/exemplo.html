# 🌐 exemplo.html

Página web de exemplo desenvolvida com **HTML5**, apresentando um site de boas-vindas com imagem e conteúdo introdutório sobre programação.

---

## 📋 Sobre o Projeto

Este repositório contém o código-fonte de uma página HTML de exemplo criada para praticar o uso de tags estruturais e de conteúdo. A página inclui cabeçalho, seção com imagem e parágrafo de boas-vindas.

---

## 🛠️ Tecnologias Utilizadas

- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) **HTML5** — estrutura da página

---

## 📚 Conceitos Praticados

- Estrutura básica do HTML (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
- Tags semânticas: `<header>`, `<section>`
- Inserção de imagens com `<img>` e atributos `src`, `alt`, `width`, `height`
- Parágrafos e títulos (`<p>`, `<h1>`)
- Título da página com `<title>`
